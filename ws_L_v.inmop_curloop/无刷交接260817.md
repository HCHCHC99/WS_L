## 二、comm_mode 说明（Keil Watch 修改 `comm_mode` 整型变量）

```c
// main.c:37
volatile int comm_mode = 0;
// 0=Stop 1=OpenFW 2=OpenRV 3=ClosedFW 4=ClosedRV 5=Calibrate 6=CalibCW 7=CalibCCW
// 8=PID_CW 9=PID_CCW 10=CurLoopFW 11=CascadeFW
// 21=FocOpenLoop 22=FocCurrentLoop 23=FocAlign
```

主循环检测 `comm_mode` 变化后：
```c
if (comm_mode == 21) Foc_StartOpenLoop();      // FOC 开环 V/f
else if (comm_mode == 22) Foc_StartCurrentLoop(); // 编码器 FOC 电流环（I-F 启动）
else if (comm_mode == 23) Foc_StartAlign();    // 静止电角度对齐
// 从 21/22/23 切走时：Foc_Stop() + TMR4_PWM_StartOutput()（释放 TMR4 给六步）
```

### comm_mode = 0 —— 停止
- `Foc_Stop()`：清 active、关 PWM 输出、占空比观测清零；FOC ISR 里 `g_foc_active==0` 直接返回。
- **MotorScope 心跳仍持续上报**（主循环调 `Foc_RttSend()`），手拧电机时编码器角度/机械角/电角度实时更新，方便纯手动验证方向。

### comm_mode = 23 —— 静止电角度对齐（重点）
- 目的：把转子锁到 d 轴，记录**编码器电零位** `s_align_offset`（对齐后 `Foc_CurLoopTheta()==0`），供 mode 22 RUN 使用。
- 流程（INMOP 风格两段式，`Foc_StartAlign`）：
  1. **beta 轴保持** `FOC_ALIGN_BETA_MS=1000ms`：小电流把转子拉向已知位置；
  2. **alpha 轴**：编码器计数稳定窗口 `FOC_ALIGN_STABLE_MS=300ms` 判定锁定 → 记录 `s_align_offset = ModPos(cnt*enc_dir, CPR)`；
  3. 锁定后保持 `FOC_ALIGN_HOLD_MS=2000ms`（够读 id/iq），超时 `FOC_ALIGN_TIMEOUT_MS=3000ms` → 故障码 3。
- 参数：`FOC_ALIGN_VOLT_V=0.4V`（≈2.5~4A，≈31mNm 锁轴，< OC 5.5A，Watch 可调 `g_foc_align_volt_v`）。
- **已确认的校准结论**：`FOC_CUR_SIGN=-1`（由 mode23 对齐确认，id 必须为正）；`FOC_ENC_DIR=-1`（mode21：+5Hz 场 → 转子 -30rpm，enc_dir=-1 使锁定时 enc_elec 跟上 theta）。

### comm_mode = 22 —— 编码器 FOC 电流环（重点，当前主调对象）
- 启动即进入电流环（非电压开环），带 **I-F 合成角启动**：
  `ia/ib/ic → Clarke → Park(theta) → id/iq → vd=PI(0,id), vq=PI(iq_ref,iq) → InvPark → SVPWM → TMR4 占空比`
- **I-F 启动状态机**（g_foc_phase：1 hold → 2 ramp/sync → 3 run）：
  1. **hold**：theta=0，Iq 软启动爬升到 `g_foc_if_hold_iq_ma=1200mA`（≈15mNm 预载），锁存角度偏移 `g_foc_if_lock_diff_rad` 作同步基线；超时 `FOC_IF_HOLD_MAX_MS=5000ms` 强制进爬频；
  2. **ramp/sync**：合成频率按 `FOC_IF_FREQ_RAMP_HZ_S=1.0Hz/s` 爬升；`≥FOC_IF_SYNC_MIN_HZ=2Hz` 开始同步检测——滑窗 `FOC_IF_SYNC_WIN_CNT=2000`（100ms）内相对偏移带宽 `<FOC_IF_SYNC_BAND_RAD=0.30rad`，连续 `FOC_IF_SYNC_GOOD_WINS=2` 个合格窗 → **交接**；`FOC_IF_TIMEOUT_MS=15000ms` 未同步 → 故障码 2；
  3. **run**（交接后）：控制角从合成角经 `FOC_RUN_BLEND_CNT=200` tick 混合到**真实编码器角**（防电流冲击）；iq 参考切到**速度 PI**（`g_foc_pid_spd_cfg.kp`，目标 `g_foc_run_target_rpm`，上限 `FOC_IQ_REF_MA=3000mA`）。
- **方向/帧组合（关键，未定论）**：`FOC_RUN_ANCHOR_DEG=180` + `FOC_RUN_IQ_SIGN=1` 是当前台架上唯一能转起来的组合（Watch 可调 `g_foc_anchor_deg` / `g_foc_run_iq_sign`）。`FOC_PI_OFF_180=0`（注意 cur_sign=-1 会抵消 pi_off，所以 pi_off 实际不改变方向）。
- 电压包络：`FOC_VMAX_V=1.0V`，爬升 `FOC_VRAMP_V_S=0.5V/s`（防上电过流）。
- 电流环 PI：Kp=0.10（fc≈375Hz@L=42.3µH）、Ki=240（零点相消）、输出钳位 1.0V。

### comm_mode = 21 —— FOC 开环 V/f（辅助）
- theta 按 `FOC_OPENLOOP_FREQ_HZ=5Hz` 积分，电压 `FOC_OPENLOOP_VOLT_V=0.9V`（5Hz 稳定同步 -30rpm；0.4V 会打滑），硬上限 1.5V。常用于方向/编码器方向的初步验证（配合 MotorScope 看转子方向）。

4. **打印性能**：MOTF 发送已在主循环 + 锁节流（事件/阈值立即发，连续量 ≥30ms，保活 300ms），不会拖慢主循环导致 handok 停转。**不建议用 DMA 优化 RTT**（RTT 是写 RAM 环形缓冲，J-Link 经 SWD 后台硬件搬运，不占 CPU；真正的开销是 snprintf 格式化，节流已解决）。如需更低开销，可切二进制帧（FOC_RTT_RATE_HZ>2000 已内置 76B 直发）。

## 四、风险与注意
- ⚠️ 母线 12V + 3A Iq + 20 磁钢，**上电前确认电流环 PI 输出钳位/电压包络**，过流默认 5.5A 会跳闸（g_foc_fault）。
- ⚠️ 堵转/飞车防护：I-F 同步超时故障码 2、对齐超时故障码 3、过流故障码 1；CommRunner 内部 STOP 会回写 comm_mode。
- ⚠️ 电机额定 17A、传感器 ±10A——对齐 0.4V 锁轴电流约 2.5-4A 安全，但**不要长时间大电流堵转**。
- 切换 21/22/23 ↔ 六步模式时，TMR4 在 FOC 互补模式与六步模式间重配，需确认 `TMR4_PWM_SetFocMode`/`StartOutput` 时序。
